# 智能问数稳定性收尾验证报告

日期：2026-09-29。对象：原项目优化版，不是用友生产环境验收。

## 已复现并修复的缺陷

`bounded_search` 原先直接等待 `asyncio.gather`。一个检索子任务异常退出时，其他子任务并不会因此全部取消，可能继续占用连接。新增事件同步测试在旧实现上稳定失败，修复后通过：正常完成、子任务失败、外层取消均清理并等待子任务退出，仍保持每批最多四个并发以及结果顺序。

这证明了一个具体资源清理缺陷，不证明它就是 9 月 27 日八次检索中断的根因。历史错误缺少依赖阶段信息；Docker 恢复后，当前版本连续完成 200 条真实模型问数且未再次出现该故障，但一次稳定运行仍不足以证明历史根因已经消除。

## 本轮代码改动

- 新增 `improved/diagnostics.py`：模型调用、字段/指标 Embedding、Qdrant 与 ES 检索使用固定阶段标识；日志仅记录阶段、白名单错误码、尝试次数、耗时和请求编号，不写原始异常正文、查询、结果、SQL、URL 或凭据。
- SSE 错误携带诊断编号、阶段与代码，便于和服务端失败日志关联。无合法请求上下文时编号为 unavailable，不接受任意文本作为日志编号。
- 只读检索/Embedding 的已知连接错误及 502/503/504 最多重试一次，带 100–300ms 随机退避。401/403、429、无效响应及其他未知异常不重试；模型保留原 SDK 重试上限，不额外嵌套重试。
- Embedding 每阶段总预算 25 秒、检索每阶段 12 秒；原请求全程 60 秒上限不变。超时和客户端取消不转换成规则答案。
- 前端流处理拆为可测试模块：支持 UTF-8 字节切分、CRLF、多行 data 与注释；无终态断流、非法 JSON、缺失数据表及超大帧明确报错；终态后释放 reader。请求接收限时 70 秒。
- 页面区分服务令牌 401、请求限流、依赖不可用和模型鉴权错误，展示安全诊断编号。
- 随机实验验证脚本支持指定本地端口，便于不修改正式配置的隔离验收。

## 环境检查与未完成验收

1. Docker Desktop 的 `sailor-ingest.sock` 访问故障已通过整体备份运行目录并创建空目录恢复。原目录保留为 `run.backup-qa-20260929` 与 `docker-secrets-engine.backup-qa-20260929`，没有删除容器、镜像或数据库卷；既有服务已重新启动。该方案是运行文件修复，不代表 Windows/Docker 底层缺陷不会复发。
2. 浏览器已验证令牌鉴权、真实查询、结果表和随机实验结果卡片。内置浏览器没有捕获到 JSON 下载事件，Windows 下载目录也没有新文件，因此导出下载仍标记未验证；移动端布局尚未验收。
3. 当前代码已完成 50 条开发集与 150 条留出集真实模型全量评测，并完成 20 条贡献分解在线集。题目由开发助手模板化生成，开发/留出共享题型，缺少独立业务人员盲测。
4. 员工 SSO、部门权限隔离、生产压测与监控体系仍未交付；公开数据测试不能替代人力业务数据授权和口径验收。
